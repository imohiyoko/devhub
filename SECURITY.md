# セキュリティポリシー / Security Policy

## 脆弱性の報告 / Reporting a Vulnerability

脆弱性を見つけた場合は、公開 Issue ではなく GitHub の
[プライベート脆弱性報告](https://github.com/imohiyoko/devhub/security/advisories/new)
から報告してください。内容を確認のうえ、修正版のリリース後に公開します。

If you find a vulnerability, please report it privately via
[GitHub private vulnerability reporting](https://github.com/imohiyoko/devhub/security/advisories/new)
instead of opening a public issue.

## 対象バージョン / Supported Versions

最新リリースのみが修正の対象です。
Only the latest release receives security fixes.
