環境の編集
※有効にすると、binding 未指定のプロセスは選択した worktree を CWD として起動します。
※worktree は git tool で作成済みの既存 worktree から選びます（env-launcher は worktree を作成・削除しません）。
※ Repository を選ぶと、この環境のプロセスは選んだ範囲からのみ binding できます（事故防止）。空なら制限なし。
プロセスの編集
shared は全シナリオに暗黙で所属します（共通の DB など）。scenario はシナリオに所属させて初めて起動対象になります。
offset は base ポート（上のポート）から空きを探し、その番号を指定 env 変数でアプリに渡します（並列 worktree 向け）。
docker compose をこのディレクトリで実行します。
devhub が操作対象を絞る所有権マーカーです（--project-name）。この project 以外のコンテナには触れません。

この環境の compose_service をどこで動かすか。ホストは host_process のみの環境向けです。
devhub は profile を起動・再構成しません。停止中なら colima start -p <profile> を実行してください。
profile が実際に使っている engine を指定します。食い違っても devhub は切り替えません（既存のイメージとコンテナに影響するため）。
